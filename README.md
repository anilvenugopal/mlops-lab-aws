# piq-mlplatform

An AWS lab demonstrating a governed ML platform for P&C insurance, built with
Terraform. Two demonstration models (total loss at FNOL, claim severity) share
a feature store to prove out feature reuse, point-in-time correctness, root
cause analysis, and a governance deployment gate.

See [SETUP.md](SETUP.md) for the full build guide, architecture, AWS account
setup, cost plan, and development workflow.
